应用名称：Jaguarmap（jaguarMap）

开发者：应用开发者（个人）

1. 我们是谁

jaguarMap 是一款非捷豹官方的个人工具应用，用于在您本人授权登录捷豹 InControl 车主门户后，查看并在地图上展示您的历史行驶轨迹。

2. 我们收集哪些信息

本应用不会向开发者或第三方运营服务器上传您的行程数据。数据主要在您的设备本地处理：

  • 车主门户会话凭证（Cookie）：用于访问您本人的行程接口，仅保存在本机应用沙盒；发行包不含真实会话。
  • 历史行程与轨迹坐标：从捷豹 InControl 中国站车主门户拉取后，缓存在本机，用于列表、统计与地图展示。
  • 手机号等登录信息：仅在门户登录流程中由捷豹官方页面处理；本应用不另建账号体系。
  • 可选生物识别：若您开启 Face ID / 触控 ID 锁定，系统仅用于本地解锁验证，我们不会采集生物特征数据。
  • 本地通知：若您开启会话提醒，仅在设备本地调度通知，不经过开发者服务器。

3. 信息如何使用

  • 仅用于应用核心功能：拉取、缓存、展示您的历史行程与轨迹，以及您主动开启的锁定与提醒。
  • 不用于广告追踪，不出售个人数据。

4. 信息如何存储与共享

  • 行程与 Cookie 默认保存在设备本地（应用沙盒）。
  • 若您使用 iCloud 备份，备份内容为行程列表缓存与车辆资料摘要，不含登录 Cookie；换机后需重新登录门户。
  • 桌面小组件通过 App Group 读取里程摘要；开启应用锁时可选择隐藏路线起终点细节。
  • 本应用不运营自有后端；网络请求直接发往捷豹相关域名（如 `incontrol.jaguar.com.cn`、身份登录域名）。
  • 除非法律要求，我们不会将您的行程数据提供给无关第三方。

5. 地图与位置

应用使用系统地图（MapKit）展示历史轨迹点，不会进行实时定位跟踪，也不会在后台持续获取位置。

6. 您的选择

  • 您可随时在应用内重新登录以更新会话。
  • 您可关闭 Face ID 锁定、会话提醒，或删除应用以清除本机缓存与凭证。
  • 您也可在捷豹官方门户管理您的车主账号与行程数据。

7. 儿童

本应用面向车辆所有者，不以儿童为目标用户。

8. 政策变更

若政策更新，将在本页面修订更新日期。继续使用即表示知悉更新内容。
